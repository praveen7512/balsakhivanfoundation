# Bal Sakhi Van Foundation website

A responsive static website built with HTML, CSS and vanilla JavaScript. It is ready to publish using GitHub Pages.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `bal-sakhi-van-website`).
2. Upload all files in this folder to the repository root: `index.html`, `styles.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Replace the sample photos with real, permission-cleared foundation photographs.
- Verify all foundation descriptions, activities, statistics and locations.
- Add the foundation's real email, phone number, address and donation/payment link.
- Update social links if needed.

The photo URLs currently load from Unsplash and require an internet connection.
